# PROJECT STRIKE 3D FPS — 0.1

A browser-based 3D FPS prototype made with HTML, CSS, JavaScript and Three.js.

## Run locally
Because `game.js` uses JavaScript modules, do not open `index.html` directly from the file manager. Serve the folder from a local web server or upload it to GitHub Pages.

## Publish free with GitHub Pages (phone-friendly)
1. Sign in to GitHub and create a **public** repository, for example `project-strike`.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root (the top level, not inside another folder).
3. Open the repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait a minute or two and open the URL GitHub Pages displays, usually `https://YOUR-USERNAME.github.io/project-strike/`.

## Controls
- PC: WASD to move, mouse to aim, left click to shoot, R to reload, Esc to pause.
- Touchscreen: left joystick to move, drag the game view to aim, FIRE to shoot, RELOAD to reload.
- Use a modern browser and an internet connection (Three.js and fonts load from CDNs).

## Notes
- This is an early single-player prototype, not a complete Valorant clone.
- The bots are simple training targets and multiplayer is not included yet.
- If GitHub Pages is not enabled, the site will not be publicly accessible.
